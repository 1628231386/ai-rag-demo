# AI 口语陪练项目说明（示例知识库文档）

> 这是给 RAG 助手演示用的示例文档。把它加入知识库后，可以问：「这个项目的服务端口是多少」「跟读打分怎么算的」「它怎么解决跨域问题」。

## 项目定位

AI 口语陪练是一个本地运行的英语口语练习网页：用户说英文 → AI 陪对话 → 纠正每一个错误 → 给更地道的说法 → 问下一个问题，还能朗读出来。主要场景是雅思口语 Part 1、日常闲聊、求职英文面试。

## 技术栈

- **后端**：Node.js，零第三方依赖，只用原生 http/https 模块
- **前端**：单页 HTML，原生 fetch，没有引任何框架
- **流式输出**：SSE（Server-Sent Events），回答逐字出现
- **语音合成**：浏览器 Web Speech API 的 speechSynthesis，本地合成不联网
- **语音识别**：优先用浏览器自带识别，失败时自动转云端 ASR（硅基流动 SenseVoice）
- **跟读打分**：录音转文字后与原句做词级比对，用最长公共子序列做对齐，漏读标红、多读标黄

## 关键设计

### 为什么要有本地代理服务

浏览器有同源策略，网页不能直接拿 API Key 去调大模型接口（会被 CORS 拦截）。所以做了一个 Node 本地代理，只绑定 127.0.0.1，请求由它转发，Key 只保存在用户自己电脑的浏览器 localStorage 里。

### 四段式 Prompt

每次回复固定输出四段：Reply（自然回应）、Mistakes（错误纠正）、Better（地道表达）、Next（下一个问题）。没有错误时 Mistakes 也会明确说 None，防止模型偷懒跳过纠错。

### 评分公式

分数 = 命中词数 ÷（原句词数 + 多读词数 × 0.5）。多读乱加词会扣分，所以它评的是「词有没有读对、有没有漏」，不是音色好不好听。

## 运行方式

服务端口是 **3210**。双击启动批处理后，浏览器访问 http://127.0.0.1:3210 使用。黑窗口不能关，关了服务就停。
